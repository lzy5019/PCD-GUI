# FUS-Probe UHE-BE 交接记录

日期：2026-07-12

## 本次变更

- FUS-Probe 交替采集改用 `UHE + BE`：每周期依次采集低压 Probe 与高压 Treatment，并配对计算指标。
- UHE 是主起效特征，积分 1.5、2.5、3.5 倍基频附近的谱功率。
- BE 是安全候选特征，在 1.25-6.25 倍基频范围内排除各 0.5 倍频谱线附近后积分。
- 删除 FUS-Probe 的 IUD 计算、参数、趋势和日志字段；软件原有独立 IUD 窗内失稳模式不受影响。
- 新增 UHE/BE 时间趋势、Probe/Treatment 频谱叠加及 UHE 谱线标记；左侧可单独隐藏 UHE、BE 和累计剂量曲线；`manifest.csv` 写入 UHE、BE 和累计安全 UHE 剂量。
- 算法 `v4` 删除 HE：不再计算整数谐波特征、不显示 HE 曲线或频谱标记，也不在采集日志和 manifest 中落盘 HE。
- Playback 设置独立保存回放点数；启动回放时该值覆盖本次分析读取长度，不再依赖采集卡点数。Hardware 模式下输出目录保持在折叠采集参数之外，始终可编辑。

## 指标定义

令 `Pp,k` 和 `Pt,k` 分别为 Probe/Treatment 在第 `k` 个频带的 PSD 积分功率，`rV = (Vt / Vp)^2` 为驱动电压功率比。任一配对特征按下式做 Probe 归一化：

`Mraw = 10 log10(sum(Pt,k) / (rV * sum(Pp,k)))`

最终显示值为 `M = Mraw - C_M`，其中 `C_M` 是用相同硬件、相同采集配置的无微泡背景确定的系统补偿。

- UHE：`k = {1.5 f0, 2.5 f0, 3.5 f0}`，每个中心频率积分正负 10 kHz。
- BE：在 `1.25 f0` 至 `6.25 f0` 内积分，但排除每个整数与半整数倍频正负 30 kHz 的区域。

这些是同周期、同耦合条件下的相对变化指标；它们不等价于绝对声压，也还不是经过生物学终点验证的 BBB 开放判定。

## 当前默认值与水槽初筛

当前采集配置：25 MHz、25,000 点、1 ms 采集窗、`f0 = 612 kHz`、Probe 4.5 Vpp、Treatment 7 Vpp。

无补偿的 UHE 中位数（dB）：water1 -3.990、air1 -3.653、air2 -3.880、mb1 +3.699、mb2 +5.457。

因此 GUI 默认 `UHE 系统补偿 = -3.8 dB`。补偿后，空白背景约为 0 dB，而 mb1/mb2 约为 +7.5/+9.3 dB。背景 UHE 95 分位最高约 +2.07 dB，因此默认 UHE 起效候选线设为 3 dB；默认 `BE 系统补偿 = -3.8 dB`、BE 风险候选线 6 dB、剂量候选线 20 a.u. 都是探索参数，不能作为临床或动物实验安全阈值。

2026-07-12 复核发现 water1、air1、air2 各有一帧聚合 UHE 越过 3 dB，但都没有 3 个子带同时越线。算法 `v3` 因此默认要求 3/3 子带一致后才累计剂量：三个背景组的累计剂量均为 0.0 a.u.；mb1/mb2 分别保留 69/113、57/78 个确认周期。

旧的未标定 FUS-Probe 设置会在加载时迁移到 3 dB；已勾选完成终点标定的设置不会被自动覆盖。

## 在线判定

1. Probe 质量不足或任一采集削顶：`invalid`，不累积剂量。
2. BE 高于风险候选线：`risk`，优先于任何起效/剂量结论，也不累积剂量。
3. 其余有效周期：UHE 聚合值高于起效候选线，且至少达到“UHE 最少一致子带”设置（默认全部 3 个超谐波子带）也高于该线，才累积线性超额 `10^(UHE/10) - 10^(阈值/10)`。这会阻断孤立的背景谱线尖峰。
4. 累计值达到剂量候选线：`open`；否则 `not_open`。

状态标签直接报告当前信号与风险状态；阈值应结合 BBB/损伤真实终点数据验证。

FUS-Probe 配对回放支持暂停/继续；暂停时仍不允许跳帧，以保证 Probe/Treatment 配对顺序和剂量状态可追溯。


## 已知限制与后续标定

- 当前 1 ms 采集窗用于频谱特征初筛；完整 6,000 cycle 激励约 9.8 ms，若需要研究脉内演化，应延长采集窗并单独验证时序定位。
- UHE/BE 的系统补偿只适用于当前水槽、换能器、前端增益、采样率、频带和电压组合。任一条件实质变化后，应重新采集空白背景并重新估计补偿。
- 要形成可报告的 BBB/安全判定，需要带独立终点标签的数据集，按动物/样本分组做训练-验证拆分，固定阈值后在盲法留出集上报告灵敏度、特异度和置信区间。
