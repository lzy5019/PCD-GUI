## 程序里的 ICD 计算方法

位置：`main.py` 中 `compute_cavitation_metrics()`。

当前经典 SCD-ICD 方法不是对全宽带直接积分，而是：

1. 对信号取前 `target_sample_count=25000` 点。
2. 默认使用 `use_segment_average=True` 和 `segment_count=2`，所以每个文件被分成两个 12500 点窗口。
3. 每段做 Hann 窗、rFFT，得到 power spectrum 后取两段平均。
4. 在 `450-750 kHz` 搜索最大谱峰作为 `f0_hz`。注意：在没有真实驱动基波的噪声数据里，这一步会被噪声峰牵引。
5. `order_range_low=1.5`，`order_range_high=5.25`，`broadband_centers_factor()` 返回 `1.75, 2.25, 2.75, 3.25, 3.75, 4.25, 4.75, 5.25`。
6. 每个中心频点取 `±75 kHz` 的窗口，算该窗口内 spectrum 的平均值。
7. ICD = `sqrt(sum(broadband_mean_i ** 2))`。

因此 ICD 对进入这些窗口的窄带串扰非常敏感。它不是只响应“真正的 inertial cavitation broadband”；只要某些固定频率干扰落入多个 ICD 窗口，ICD 就会显著升高。

以固定 `f0=608 kHz` 估计，ICD 窗口中心约为：

- 1.064 MHz
- 1.368 MHz
- 1.672 MHz
- 1.976 MHz
- 2.280 MHz
- 2.584 MHz
- 2.888 MHz
- 3.192 MHz

用户提到功放可能产生 `72 kHz` 串扰，这与 ICD 窗口高度可疑地对齐：

- 19 * 72 kHz = 1.368 MHz，正好命中一个 ICD 中心。
- 36 * 72 kHz = 2.592 MHz，离 2.584 MHz 只差 8 kHz。
- 40 * 72 kHz = 2.880 MHz，离 2.888 MHz 只差 8 kHz。
- 15/23/27/32/44 次也都在 ±32 kHz 范围内，落入 `±75 kHz` 宽带窗口。

这意味着如果功放或其供电/地线/附近电磁场中存在 72 kHz 基频或纹波，它的高次谐波会被 ICD 算法系统性计入。

## 对硬件问题的当前判断

最可能问题不是采集卡本体，而是 PCD 接入后形成的接收天线/地耦合问题。

高度怀疑链路：

1. 功放、功放电源、其开关电源/驱动、或地回路产生低频纹波/串扰，用户观察到约 `72 kHz`。
2. 这个串扰以电场/磁场/地电位差方式存在于实验台附近。
3. PCD 探头外壳、铜胶带、BNC 屏蔽层、线缆和光学平台/示波器地之间形成拾取结构。
4. 如果线缆靠近功放或构成较大环路，串扰显著进入 PCD/采集卡输入。
5. 这些干扰的高次谐波落入 ICD 宽带窗口，导致 ICD 偏高。

为什么第 5 组最关键：

- 第 5 组只是改变线缆摆放位置，ICD 从第 4 组的 `~9e-5` 降到 `~3e-5`，回到采集卡基线。
- 这个变化量远大于统计波动，说明线缆空间耦合和环路面积是主要变量。

为什么第 6、7、8 组不能简单说明“接地无所谓”：

- 第 6 是夜间数据，用户已经怀疑下班后空间干扰消失，这与结果吻合。
- 第 7、8 是下午重测，结果也低，说明当时环境或线缆状态可能已经进入低耦合状态。
- 当前最好的实验是第 9：把线缆摆放位置放回靠近功放的位置，再测一组。若 ICD 再升高，就几乎可以钉死“线缆位置/功放近场耦合”。

## 算法层面的注意事项

在噪声测试中，自动估计 f0 会产生误导。

例子：

- 第 1、2 组固定 608k ICD 约 `3e-5`，但自动估计 f0 ICD 约 `4.9e-5`。
- 第 1、2 组自动 f0 中位数是 `488 kHz`，这显然不是真实驱动基频，而是噪声谱峰。
- 第 8 组固定 608k ICD 为 `3.10e-5`，自动估计 f0 ICD 为 `3.71e-5`，自动 f0 中位数为 `572 kHz`。

建议：

- 做硬件底噪排查时，固定 f0 为发生器设置值，例如 `608 kHz`。
- 正常 cavitation 实验可以继续自动估计 f0，但前提是基波峰足够强。
- 若要在软件中增强鲁棒性，可增加一个“固定 f0 / 使用信号发生器 f0”的选项，或当 `450-750 kHz` 峰显著性不足时禁止自动 f0。
- ICD 目前用窗口均值，不做局部噪声扣除；这适合当前 reference 体系，但对窄带串扰敏感。若硬件无法完全消除，可考虑加“剔除窄带尖峰/局部 baseline 扣除”的诊断模式，但不要直接替换 reference 算法，除非重新建立 reference。

- 第 11 组，手握 PCD：

  - 时域 std 中位数：`0.649 mV`
  - `128 kHz` 峰幅值中位数：`0.104 mV`

解释：

- 手握后 `128 kHz` 主峰几乎没有变，所以第 11 组变差不是因为 128 kHz 主噪声本身明显增大。
- 真正变大的是 ICD 关心的 MHz 频带，尤其 `1.30-1.43 MHz` 和 `1.0-3.3 MHz` 频带，约放大 3.3 倍。
- 手握 PCD 在这个接法下更像“人体电容天线”，不是可靠接地。人体通过对市电/设备/空间电场的电容耦合，把共模噪声加到浮空外壳/屏蔽层/晶片附近，再经 PCD 内部寄生电容和采集卡输入阻抗转换成差模信号。
- 过去手握变小，可能是当时 PCD 外壳/铜胶带处于更浮空、更高阻的状态，人体提供了阻尼或近似参考地；现在系统状态不同，人体反而引入更多共模噪声。

下一步建议：

- 做“手握是否接地”的四象限实验：
  1. 不手握。
  2. 手握但人体悬浮，不碰任何金属。
  3. 手握，同时另一只手摸采集卡地/BNC 外壳。
  4. 手握，同时另一只手摸光学平台或功放外壳。
- 如果 3 变好而 4 变差，说明采集卡地是较干净参考，平台/功放地较脏。
- 如果 2 就变差，说明人体本身在该环境下是电场接收天线。
- 如果用铜胶带/外壳单点接采集卡地后，手握影响消失，说明主要路径是浮空外壳电容耦合。
